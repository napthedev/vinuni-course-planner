## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Updating course data

Replace `scripts/index.html` with the latest course-list HTML, then run:

```bash
npm run parse
```

The parser regenerates `src/data/courses.json` and
`src/data/courses.meta.json`. Commit both generated files together with
`scripts/index.html`. The displayed update date comes from the latest Git
commit that changed the source HTML; uncommitted changes use today's date in
the Vietnam timezone for local preview. Re-running the parser without changing
the input leaves the generated files untouched.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
